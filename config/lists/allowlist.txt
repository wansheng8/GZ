# 自定义白名单（LocalAllowlist）
#
# 本文件承载维护者自有的放行规则，以 @@ 例外规则表达，在 dedupe 之前作为独立
# 来源（LocalAllowlist）并入流水线。
#
# 作用与优先级：
#   - 优先级最高：覆盖自定义黑名单与全部上游阻断。
#   - DNS 白名单产物 dns_allow.txt 完全来自本文件的整域全局例外。
#   - DNS 阻断集合的例外来源收敛为本文件；上游例外不再参与 DNS 层剔除。
#
# 格式：标准 AdGuard / uBO 例外语法，支持裸域名简写：
#   example.com                 # 等价于 @@||example.com^
#   @@||example.com^
#   @@||cdn.example.com^
#
# 注意：含通配的误伤规则会阻断构建。
#
# 示例（仅供格式参考，默认注释，按需取消注释或替换为真实目标）：
# @@||example.com^
